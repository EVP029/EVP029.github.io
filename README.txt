E V P portfolio: static site (HTML, CSS, a little JS). No build step.

To test: open index.html in your browser.

To publish for free with GitHub Pages:
1. Create a public repository on github.com (for example: portfolio).
2. Upload all the files and the assets folder from this folder, keeping the structure.
3. In the repository go to Settings > Pages, choose "Deploy from a branch", branch main, folder /(root), and Save.
4. After a minute the site is live at https://YOUR-USER.github.io/portfolio/

Pending in the files: the Instagram link (search for instagram.com in each page) and the images (placeholders marked with a dashed box).
